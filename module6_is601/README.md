## Project Description

This is a calculator application with history capabilities, able to do not only the basic operations, but also able to calculate modulus, integer division, percentages, and absolute differences.

## Setup

Create a copy of this repository, make a virtual environment and start it up, install the requirements with pip, and start up the application with "python main.py".

## .env

The .env file has the following environment variables:
CALCULATOR_MAX_HISTORY_SIZE=100
CALCULATOR_AUTO_SAVE=true
CALCULATOR_DEFAULT_ENCODING=utf-8

## Usage Guide

Once the program is underway, you can type one of the integrated operations (which can be viewed through typing in 'help').

## Testing

Once in the virtual environment, type in "pytest" to run the automated test.
